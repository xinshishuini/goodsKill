# goodsKill - AI Gateway & Microservice Platform

本项目是一个基于 Spring Cloud 的高并发秒杀与 AI 能力接入平台，核心聚焦于统一网关、微服务治理、权限认证和 AI 能力封装等方面。项目在保留原有扩展能力的基础上，强调其作为后端/AI 工程实践项目的主线价值，适合用于项目展示、实习经历和岗位投递。

## 项目定位

本项目围绕以下核心问题展开：
- 如何统一管理多个微服务入口？
- 如何通过网关实现路由、鉴权和流量管理？
- 如何在高并发场景中保证秒杀逻辑的安全性与一致性？
- 如何将 AI 能力统一封装为服务能力供业务调用？

因此，项目的主线可以概括为：

AI 网关 + 微服务接入 + 权限控制 + 分布式能力 + 高并发场景

## 核心模块

项目中最适合展示的核心模块如下：

- goodskill-gateway
  - 统一 API 入口
  - 路由转发
  - 权限校验与流量控制
  - 面向微服务统一访问

- goodskill-auth
  - 登录与权限认证
  - 用户访问控制
  - 统一鉴权能力封装

- goodskill-ai
  - AI 能力接入
  - 知识库管理
  - 模型调用封装与统一异常处理

- goodskill-common
  - 公共组件
  - 通用返回封装
  - 工具类与基础服务能力

- goodskill-order-provider
  - 订单业务服务
  - 业务处理逻辑的微服务化实现

- goodskill-seckill-provider
  - 秒杀核心逻辑
  - 库存处理与业务时序控制

- goodskill-web
  - 秒杀模拟接口入口
  - 业务触发层

## 项目亮点

### 1. AI 能力接入

项目中 goodskill-ai 模块体现了对 AI 能力的集成与封装，支持：
- AI 对话
- 知识库管理
- 模型调用统一封装
- AI 对业务流程的辅助接入

这使项目不仅适合后端工程展示，也兼具 AI 服务接入能力。

### 2. 统一网关能力

goodskill-gateway 负责统一请求入口，对不同微服务进行路由和访问管理，体现了常见的 API 网关设计能力：
- 路由转发
- 鉴权控制
- 统一访问入口
- 业务能力聚合

### 3. 高并发场景设计

项目中的秒杀模块展示了高并发场景下的关键思路：
- 分布式锁
- Redis 缓存
- Kafka 消息处理
- 数据一致性处理
- 限流与请求控制

### 4. 工程化能力

项目整体保留了较完整的工程化结构，包括：
- 多模块设计
- 公共组件抽象
- 统一配置中心
- 中间件接入
- 多场景业务支持
